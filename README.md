# ReadableMD Privacy Policy

**Last updated:** October 22, 2026

> **ReadableMD is privacy-focused.** Markdown content is processed locally in your browser. ReadableMD does not upload your documents to a developer-controlled server.

## 1. What ReadableMD does

ReadableMD converts Markdown content from local files and web pages into a readable document view. It supports formatting, code highlighting, Mermaid diagrams, mathematical notation, themes, navigation, presentations, and exports.

## 2. Information processed locally

To provide its features, ReadableMD may process the following information locally on your device:

- Markdown or page content while it is being rendered.
- Your display preferences, such as theme, font, width, and layout settings.
- Recent-document metadata, such as a document title, URL, and last-accessed time.
- Temporary rendering data, file handles, URL metadata, and in-memory caches.

Document content is not sent to ReadableMD servers. ReadableMD does not use document content for advertising, profiling, analytics, or artificial intelligence training.

## 3. Chrome permissions

**Storage:** Used to save preferences, recent-document metadata, and temporary local data in Chrome.

**Web page and file URL access:** Used to detect and render Markdown content on supported web pages and local Markdown files. Processing takes place locally in the browser.

## 4. Sharing and sale of information

ReadableMD does not sell, rent, or transfer user data to third parties. ReadableMD does not include advertising, analytics, tracking pixels, or user accounts.

## 5. Retention and deletion

Preferences and recent-document metadata remain in Chrome until you remove them, uninstall ReadableMD, clear the extension’s storage, or use the available clear-data controls. Temporary caches may expire automatically. You can clear local cache data from ReadableMD settings.

## 6. Children’s privacy

ReadableMD does not knowingly collect personal information from children or any other users.

## 7. Changes to this policy

If this policy changes, the updated version will be published at this URL with a new “Last updated” date.
